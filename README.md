# 🐶 Frank's Dog Explorer

## Features

- **Breed Search**: Search through hundreds of dog breeds.
- **Detailed Profiles**: View temperament, life span, and physical descriptions.
- **Dark Mode**: Toggle between light and dark themes for comfortable viewing.
- **Secure Key Storage**: Your API key is stored locally in your browser.
- **Responsive Design**: Works seamlessly on desktop and mobile devices.

## Getting Started

### Prerequisites

You will need an API Key from The Dog API.
👉 **[Get your free API Key Here](https://thedogapi.com)**

### Installation

1. Clone the repository.
2. Open `index.html` in your browser.

## Usage

1. When you first load the app, you will be prompted to enter your **API Key**.
2. Enter a breed name (e.g., "Pomeranian") in the search bar.
3. Click a breed from the list to view its photo and details.
4. Use the 🌙 / ☀️ button to toggle themes.

## Technologies Used

- **HTML**: Semantic structure.
- **CSS**: Custom styling with CSS Variables for theming.
- **JavaScript**: Async/Await for API fetching and DOM manipulation.
