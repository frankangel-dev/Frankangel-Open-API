# 🐾 BreedDex

A responsive web application to search and browse dog breeds using The Dog API.

## Features

- **Breed Search**: Instantly search through hundreds of dog breeds.
- **Browse All**: View a grid of all available breeds with smooth entry animations.
- **Detailed Profiles**: View temperament, life span, height, weight, and history.
- **Dark Mode**: Toggle between light and dark themes.
- **Responsive Design**: Works seamlessly on desktop and mobile devices.
- **API Key Management**: Your API key is stored locally in your browser for convenience.

## Getting Started

### Prerequisites

You will need a free API Key from The Dog API.
👉 **[Get your free API Key Here](https://thedogapi.com)**

### Installation

1. Clone the repository:
    ```bash
   git clone https://github.com/frankangel-dev/Frankangel-Open-API.git
   ```
2. Open `index.html` in your browser.

## Usage

1. **Enter API Key**: When you first load the app, you will be prompted to enter your API Key.
2. **Search**: Enter a breed name (e.g., "Pomeranian") in the search bar.
3. **Browse**: Click "Browse All" to see a gallery of dogs.
4. **View Details**: Click any card to view the full profile.
5. **Theme**: Use the 🌙 / ☀️ button to toggle themes.

## Technologies Used

- **HTML**: Semantic structure.
- **CSS**: Custom styling, CSS Variables, Flexbox, Grid, and Animations.
- **JavaScript**: Async/Await for API fetching, DOM manipulation, and View Transitions.
- **The Dog API**: External data source for dog breed information and images.
